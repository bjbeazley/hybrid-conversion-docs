# Antique Hybrid Conversion Project

## Activity

**2026-11-05:**

It's been a long time since I worked on this project. I had a long road trip to prepare for which took up most of my free time in the spring and early summer.
When I got back in late August I started preparing for this project by cleaning the garage and attic to create a better workspace.
Today I ordered a Zombieverter VCU, enclosure, and board headers / connectors.
I went with the Zombieverter because it allows for a lot of flexibility compared to more out of the box EV motor controllers and vastly less effort than reverse engineering motor control CAN messages from a functioning Leaf.

---

**2026-04-26:**

I ordered an electric motor from a 2012 Nissan Leaf from a local salvage yard in Hayward CA. I used a 2012 nissan leaf because the inverter is decoupled from the motor. Based on approximate CAD models I created from measurements of B/C series IH frames the later generation motors with the attached inverter may be more challenging to fit.
I did not order an inverter at the same time because the salvage yard seemed confused about ev motors and I was hoping I might get the inverter too which would have been a great deal. Unfortunately when I picked it up a few days later I just got the motor.
